# RECRUITER

## Qué demuestra este repo

- criterio para distinguir contenedores de unikernels
- diseño de laboratorio modular
- capacidad de aterrizar una tecnología avanzada a una UX entendible
- separación entre capa operativa (WSL2/Linux) y capa producto (Windows launcher)
- documentación honesta: no se promete Windows nativo donde no corresponde

## Narrativa útil

`docker-labs` muestra reproducibilidad y operación de stacks.

`unikernel-labs` muestra especialización, benchmarking y diseño de una **suite local v1** gobernada desde Windows con backend Linux.
